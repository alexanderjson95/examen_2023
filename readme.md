## Description

CineReel is a Android app designed to help filmmakers in every step of the filmmaking process. The application allows users to 
find projects /+ other users, chat, create and manage projects and create schedules within each project. The goal of this app is to
organize project management during the full process of a project, while also centralising the core aspects of a film production: 
* Staffing/Finding projects to join
* Communication before and during a project
* Scheduling

## Installation

Follow these steps to download and run the project locally:


### 1. Choose a Folder
Pick or create a folder where you want to store the project files.
You will also need to clone the Java backend from the second repo mentioned below. 


### 2. Open Command Prompt in That Folder
- Click the **address bar** in your File Explorer.
- Type `cmd` and press **Enter**.  
  This opens Command Prompt in the same directory.

### 3. Clone the Repository
Run the following command:

Frontend:

```bash
git clone https://github.com/alexanderjson95/examen_2023.git
```
Backend:

```bash
git clone https://github.com/alexanderjson95/backend_backup_examen.git
```
